How to Install in WordPress

  1. Click the Download Plugin button above to get the latest .zip file.
  2. Go to your WordPress Dashboard → Plugins → Add New Plugin.
  3. Click Upload Plugin at the top, choose the downloaded .zip file, and click "Install Now".
  4. Activate the plugin.
  5. Configure: Go to Settings → Login Guard to set your secret URL and security options.
  6. Bookmark your new Secret Entry URL immediately — you'll need it to log in.

Optional: If you hit a 404 on first use, go to Settings → Permalinks and click Save Changes.

Jacker Login Guard Features

Why Choose This Plugin?

Built from the ground up to solve real security problems without slowing down your site.

Hidden Entry URL

Hides wp-login.php and wp-admin from public view. Only your secret slug is reachable.

Signed Access Tokens

HMAC-SHA256 signed, 5-minute cookies. Even if someone guesses your URL, they can't reach the login form without a valid token.

Cloudflare Aware

Securely detects real visitor IPs behind Cloudflare. Cloudflare headers are only trusted when the request originates from an official Cloudflare IP range. Full IPv4/IPv6 & CIDR support.

Zero Bloat

No heavy JavaScript on the frontend. External API calls are limited to admin-side geo lookups and a 7-day cached Cloudflare IP refresh — never on public page views.

Passkey & 2FA Friendly

Unlike older plugins that break modern auth, our architecture ensures WordPress 6.3+ Passkeys and popular 2FA plugins work flawlessly.

Smart Blocking

Returns 0.0.0.0, 404, or 403 to unauthorized scanners — hiding your site's existence and wasting their resources.

Auto-Block & Escalation

Suspicious IPs are auto-blocked after a configurable number of attacks, expire automatically, and repeat offenders escalate to the permanent blacklist.

Trusted IP Window

After a successful login, the same IP is protected from auto-blocking for a configurable window — so you never lock yourself out.

Three Logging Systems

Login Events, Access Log (with referer + status filter), and Auto Block List. Plus an admin operation audit with 15-minute deduplication.

Live Preview

Clean & Intuitive Admin Interface

No bloated menus. Six clean tabs: Dashboard, Settings, Login Events, Current Login, Access Log, and Auto Block List.

The Story

Why I Built This Plugin

This plugin was born from frustration. My site was repeatedly targeted: hackers kept resetting admin passwords, escalated to mass-creating fake admin accounts, and finally installed a malicious backdoor plugin to steal data.

I needed something lightweight, effective, and modern — that respects Core Web Vitals and works seamlessly with WordPress 6.3+ Passkeys. Existing solutions were either too heavy or broke modern authentication features.

So I built it myself. No tracking, no upsells, no bloat. Just pure, lightweight security that does one thing exceptionally well: protecting your login page.

FAQ

Frequently Asked Questions

What happens if I forget my Secret Entry URL?
If you have access to your hosting file manager or FTP, rename the plugin folder (e.g., to jacker-login-guard-disabled) to temporarily disable it, then log in via the standard wp-login.php. Once logged in, reactivate the plugin and check the settings.
Does this plugin support Passkeys and 2FA?
Yes. Our signed cookie mechanism is designed to be fully compatible with WordPress 6.3+ Passkeys and popular 2FA plugins. It does not interfere with the authentication flow.
Will this slow down my website?
No. The plugin uses extremely lightweight PHP hooks and object caching. It does not load any heavy scripts or stylesheets on your frontend pages.
Does this plugin support multisite?
Yes. However, settings are managed per-site, not network-wide.
How does the Attack Detection work?
The plugin automatically detects suspicious User-Agent strings, empty or short User-Agents, encoded malicious content (SQL injection, XSS, command injection), invalid request methods, and high-frequency requests (120+ per minute). Detected attacks are counted. After the configured number of attempts, the IP is auto-blocked.
How does auto-unblock work?
Auto-blocks expire after the configured duration. Once expired, the IP is automatically unbanned.
How does escalation work?
Every auto-block cycle is counted. When the count reaches the configured threshold, the IP is added to the permanent blacklist, which never expires unless manually removed.
What is the Trusted IP Window?
After a successful login, the same IP is protected from auto-blocking for a configurable number of days. This prevents the admin from accidentally blocking themselves when their session expires.
What is the API Whitelist for?
By default, all REST API endpoints are blocked. If you use plugins like Jetpack, WooCommerce, or custom APIs, add their endpoint paths to the whitelist. Example: /wp-json/jetpack/v4/, /wp-json/woocommerce/v1/.
What is the Access Log?
The Access Log records requests to sensitive resources: login page attempts (allowed and blocked), wp-admin access attempts, REST API calls (whitelisted endpoints), XML-RPC requests, and configuration file access attempts. Each entry shows the target path, the referer, and whether it was allowed or blocked. Normal page views (homepage, posts, categories) are NOT logged.
Which IP formats are supported?
Whitelist and Blacklist accept one entry per line:
  • Single IPv4 — 192.168.1.100
  • Single IPv6 — 2001:db8::1
  • IPv4 CIDR — 192.168.1.0/24
  • IPv6 CIDR — 2001:db8::/32
  • IPv4 range — 192.168.1.10-192.168.1.50
  • IPv6 range — 2001:db8::1-2001:db8::ffff
  • Inline comment — 192.168.1.100 # My Office
