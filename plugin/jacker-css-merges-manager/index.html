Powerful Features, Zero Bloat

Engineered for the real WordPress performance problem.

One Request Per Page

Combines every enqueued local CSS file into a single merged file. 20+ requests become 1. Same bytes, fraction of the latency.

Icon Font Safe

Font Awesome, Elementor Icons, Dashicons, and other icon libraries are automatically excluded. No more missing glyphs after merging.

Per-Page Cache

Each page gets its own merged file, based on the exact CSS it loads. No cross-page contamination. No wasted bytes.

Admin Bar Controls

Purge This Page or Purge All from the WordPress admin bar. One click, from any page, no need to visit settings.

Smart Cache Invalidation

Auto-purges on post save, theme switch, plugin update, menu change, and widget update. No manual cache management needed.

URL Rewriting Safe

Every url() inside merged CSS is rewritten to absolute paths. Background images never 404. Uses wp_styles base_url for accuracy.

Zero JavaScript Impact

Does not touch any script. No defer, no lazy, no async. jQuery and Elementor JS keep loading exactly as before. No breakage.

OneWebP Aware

Auto-detects Jacker OneWebP. Rewrites background-image URLs inside merged CSS to the generated .jo.webp files. Full pipeline integration.

Frequently Asked Questions

Everything you need to know about Jacker CSS Merges Manager.

Will this break my site?

No. The plugin only reorganizes <link> tags. It never modifies CSS content, never touches JavaScript, and never adds inline styles. Icon font libraries are automatically excluded. If anything looks wrong, deactivate the plugin and everything returns to normal instantly.

Why not use Critical CSS instead?

Critical CSS solves "first screen only needs a small part of the CSS." Your real problem is different: many small CSS files, each adding a network round trip. Merging directly reduces request count, which is where the seconds are actually lost.

Will it delay my page or cause flash of unstyled content?

No. The merged CSS loads the same way as before — blocking, in the <head>. The browser waits for one file instead of twenty. Same behavior, one request. No FOUC, no layout shift.

What about icon fonts?

Font Awesome, Elementor Icons, Dashicons, IcoMoon, Ionicons, and several other icon libraries are automatically excluded from merging. They load as separate files exactly as before. No more missing glyphs.

Does it work with Elementor, WooCommerce, Gutenberg?

Yes. All three are fully supported. Elementor's per-page CSS, WooCommerce product styles, and Gutenberg block styles are all merged into one request without breaking layout.

How does per-page cache work?

Each page gets its own merged file, hashed by the exact CSS it loads. Purging one page does not affect any other page. New pages regenerate on first visit. Content updates auto-purge via WordPress hooks.

Does it work with Jacker OneWebP?

Yes. JCSSMM auto-detects Jacker OneWebP. When active, it rewrites background-image URLs inside merged CSS to point at the .jo.webp files Jacker OneWebP generated. Both plugins work independently and integrate cleanly.

Is this really 100% free?

Yes. Jacker CSS Merges Manager is completely free, open-source (GPL-2.0+), and will always be free. No hidden costs, no premium versions, no API calls, no server requirements.
