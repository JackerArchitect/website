Powerful Features, Zero Bloat

Engineered for performance, privacy, and ease of use.

100% Local & Private

No third-party APIs. Your images are processed directly on your server using native PHP. Maximum privacy.

Smart Memory Engine

Dynamically calculates memory requirements and adjusts batch sizes. Prevents 502 errors on shared hosting.

Smart Queue Lazy Load

Boosts LCP scores. Critical images load instantly with fetchpriority="high", others lazy-load via smart queue.

Auto Downscaling

Automatically resizes massive images (e.g., >3000px) during conversion. Saves bandwidth effortlessly.

One-Click Dashboard

Beautiful, native WordPress UI. Real-time stats, progress bars, and bulk optimization with a single click.

Server Health Monitor

Proactive warnings for low disk space (<500MB) and RAM (<64MB). Prevents disasters before they happen.

Built to Crush Core Web Vitals

Google prioritizes fast, lightweight websites. OneWebP is specifically engineered to improve your Largest Contentful Paint (LCP) and Cumulative Layout Shift (CLS).

  • Converts heavy JPG/PNG to next-gen WebP (up to 80% smaller).
  • Smart Lazy Loading ensures above-the-fold images load instantly.
  • Zero external scripts means no render-blocking resources.

Image Types to Convert
Format Support Notes: ✅ JPEG/JPG → WebP: Fully supported. Best compression results.
✅ PNG → WebP: Fully supported. Transparent background is preserved.
⚠️ GIF → WebP: Static GIF only. Animated GIFs will become static (first frame only). GD library does not support GIF animation.
❌ SVG: Not supported. SVG is a vector format and cannot be converted by GD library.
❌ BMP/TIFF: Not recommended. Very large file sizes may cause memory issues.
❌ WebP: Already WebP. No conversion needed.
